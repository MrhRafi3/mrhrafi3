## About Me

Hi, I'm **Rafi** — a developer focused on building mobile applications with **Flutter and Dart**.

I enjoy turning ideas into practical digital products, creating clean user interfaces, and improving the details that make an application feel intuitive and polished.

Alongside mobile development, I'm strengthening my foundation in **C++, Data Structures & Algorithms, and web development**. I believe the best way to improve as a developer is to keep building, experiment with new ideas, and learn from every project.

- 📱 **Primary focus:** Flutter & Dart
- 🧠 **Problem solving:** C++ and Data Structures & Algorithms
- 🌐 **Exploring:** React and modern web development
- 🛠️ **Approach:** Build, test, refine, and keep learning
- 📍 **Based in:** Bangladesh
